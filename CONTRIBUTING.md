# Contributing

Thanks for contributing to Polytext.

## Setup

1. Fork and clone the repository.
2. Run `composer install`.
3. Run `composer test`, `composer analyse`, and `composer format:test` before opening a pull request.

## Pull Requests

- Keep changes focused and covered by tests.
- Follow existing code style (Laravel Pint preset).
- Update `CHANGELOG.md` under `Unreleased` for user-visible changes.

## Releases

Releases follow SemVer. Tag releases as `vMAJOR.MINOR.PATCH` and publish to Packagist.
